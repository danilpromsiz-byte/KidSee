Политика конфиденциальности приложения KidSee

Дата последнего обновления: 21 октября 2026 г.

Настоящая Политика конфиденциальности регулирует порядок обработки информации мобильным приложением KidSee (идентификатор пакета: com.kidsee.app), разработанным для обеспечения безопасности детей и родительского контроля на устройствах под управлением Android (включая смартфоны, планшеты и Android TV).

Главный принцип приватности:
KidSee работает по технологии локальной сети (Local Area Network / Wi-Fi). Изображение с экрана ребенка, аудиосообщения и команды передаются напрямую между устройствами родителя и ребенка внутри вашей домашней сети Wi-Fi без отправки видео- и аудиопотоков на сторонние облачные сервера.

1. Назначение приложения и специальные разрешения

KidSee является программным обеспечением родительского контроля. Для выполнения основных заявленных функций приложение запрашивает следующие специальные разрешения:

1.1. Использование AccessibilityService API (Специальные возможности)

Приложение KidSee использует AccessibilityService API исключительно со следующими целями:

  • Определение имени активного приложения на детском устройстве (для информирования родителя о том, в какой программе находится ребенок).
  • Анализ наличия элементов воспроизведения видео (например, в YouTube, онлайн-кинотеатрах) для предоставления родителю функций удаленной паузы/воспроизведения.
  • Применение ограничений экранного времени и блокировка экрана по расписанию, установленному родителем.

Важное раскрытие информации: AccessibilityService API НЕ используется для скрытого шпионажа, перехвата вводимого текста (кейлоггинга), чтения личных переписок, банковских паролей или передачи персональных данных третьим лицам.

1.2. Использование MediaProjection API (Трансляция экрана)

Приложение запрашивает разрешение на захват экрана исключительно для передачи живого изображения экрана детского устройства на устройство родителя в режиме реального времени. Стрим экрана передается только внутри локальной сети Wi-Fi, не сохраняется на постоянных серверах и запускается только с явного согласия пользователя через стандартный системный диалог Android.

1.3. Микрофон и аудиозапись (RECORD_AUDIO)

Разрешение на доступ к микрофону используется родительским устройством исключительно в момент нажатия кнопки «Удерживайте для связи» для отправки коротких голосовых заметок ребенку (режим рации). Записи передаются локально на устройство ребенка и автоматически удаляются из временного кэша.

1.4. Фоновые службы (Foreground Services)

Приложение использует типы служб connectedDevice, dataSync, mediaProjection и microphone для поддержания стабильной связи между родительским и детским устройством в фоновом режиме даже при выключенном экране или работе других программ.

2. Безопасность и хранение данных

  • Хранение данных: Все настройки (PIN-код, ID семьи, список сопряженных устройств) сохраняются локально в зашифрованном хранилище DataStore/SharedPreferences устройства.
  • Шифрование: Передача команд и данных по локальной сети защищена и изолирована домашней сетью.
  • Удаление данных: Пользователь в любой момент может удалить сопряженные устройства, очистить кэш приложения или отозвать разрешения через меню «Настройки».

3. Защита конфиденциальности детей (COPPA и GDPR-K)

KidSee полностью соблюдает требования законодательства о защите конфиденциальности детей в Интернете (COPPA) и регламента GDPR:

  • Приложение не собирает персональные данные детей для маркетинга, профилирования или таргетинга.
  • В приложении полностью отсутствует реклама (No Ads) и сторонние аналитические трекеры поведения.
  • Все функции мониторинга находятся под полным контролем родителей.

4. Контактная информация

Если у вас возникли вопросы относительно настоящей Политики конфиденциальности или работы приложения KidSee, вы можете связаться с нами по электронной почте: support@kidsee.app.

Privacy Policy — KidSee

Last updated: October 21, 2026

This Privacy Policy governs the manner in which KidSee (package: com.kidsee.app) handles data. KidSee is a parental control application designed to assist parents in supervising child activity on Android devices (phones, tablets, and Android TV).

Core Privacy Architecture:
KidSee operates primarily over a Local Area Network (LAN / Wi-Fi). Child screen mirroring, voice intercom messages, and remote controls stream directly device-to-device across your private local network without relaying audio/video through external cloud servers.

1. AccessibilityService API Disclosure

KidSee uses the Android AccessibilityService API solely to provide parental control functionality:

  • To identify the currently active foreground application to keep parents informed of their child's digital activity.
  • To inspect whether video playback elements are active (e.g. YouTube, media players) to provide parents with remote pause/play controls.
  • To enforce screen lock rules and schedules set by the parent.

Prominent Disclosure: The AccessibilityService API is never used to record keystrokes, capture passwords, read private chats, or collect sensitive personal data.

2. Screen Capture (MediaProjection API)

Screen capture is used solely to stream the child device screen to the authorized parent device on demand over the local Wi-Fi network. No video recordings are uploaded to external public servers.

3. Audio & Voice Intercom

The microphone permission (RECORD_AUDIO) is used exclusively on the parent device during push-to-talk interactions to transmit audio notes to the child device. Audio recordings are stored temporarily in cache and are not shared with third parties.

4. Children's Privacy (COPPA & GDPR-K Compliance)

  • KidSee contains zero third-party advertisements.
  • KidSee does not track, sell, or monetize children's data.
  • All administrative settings are safeguarded by a Parent PIN code.

5. Contact Us

If you have any questions or requests regarding your data, please contact us at: support@kidsee.app.
